Measure system folders
Runs once, read-only, after you approve the macOS admin prompt — nothing keeps admin rights afterwards. Results stay private to you, and sensitive system folders are recorded as totals only. Pulse won't delete anything here; use the Finder buttons, and macOS will ask for your password before deleting.
Let the scanner see everything — read-only
  1. Click Set up… — System Settings opens at Full Disk Access, and Finder shows Pulse Scanner.
  2. Drag Pulse Scanner into the list (or click + and pick it), and make sure it's switched on.
  3. Come back and click Rescan.
Only the scanner gets this access. It can list folders and read sizes, but it contains no code that can change or delete files. The part of Pulse that deletes things doesn't get Full Disk Access, so macOS still blocks it from protected folders unless you approve a specific one.
